# Bilder & Screenshots

In diesen Ordner können Screenshots der Home-Assistant-Dashboards gelegt werden. GitHub zeigt sie anschließend direkt in der Dokumentation an.

Empfohlene Dateinamen:

- `uebersicht.png` – Gesamtübersicht
- `ortsuebersicht-ibbenbueren.png` – Ortsübersicht
- `letzter-einsatz-ort.png` – letzter Einsatz eines Ortes
- `historie.png` – Einsatzhistorie
- `einstellungen.png` – Einstellungsseite der Integration

Ein Bild wird in einer Markdown-Seite so eingebunden:

```markdown
![Beschreibung des Bildes](images/dateiname.png)
```

Für das Haupt-README lautet der Pfad beispielsweise `docs/images/uebersicht.png`.
